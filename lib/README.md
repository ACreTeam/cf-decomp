# lib

Library sources and headers copied verbatim from other decompilation projects.
Some of these translation units match City Folk exactly (`Matching` in
`configure.py`) and the rest are imported as `NonMatching` starting points.

## Retail build quirks handled in the sources

- The retail linker dead-strips functions nothing references, but the string / literal pools of the translation
  unit stay. Functions that are absent from City Folk are therefore either left in the source (when the pool they
  leave behind has to appear at the right place, e.g. `WUD.c`, `dvd_broadway.c`, `OSPlayRecord.c`) or wrapped in
  `#if 0 // not linked in City Folk` with `DECOMP_FORCE_STRING(module, "text")` (`lib/common/include/global/decomp/utils.h`)
  keeping their strings in place.
- Section alignment of an imported unit follows the target split: if a neighbouring unit is shifted, fix the split
  `align:` of the next translation unit (see `config/RUUE01_00/splits.txt`).
- `EXIBios.c` is built with `-schedule off`.
